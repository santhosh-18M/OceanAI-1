# 🌊 OceanAI – AI Powered Maritime Safety & Fishermen Assistance Platform

## 📌 Problem Statement

Fishermen often face challenges such as:

- Accidental entry into international maritime borders
- Lack of real-time weather information
- Difficulty locating high-yield fishing zones
- Limited communication with family members
- Delayed emergency response during distress situations

OceanAI is designed to improve maritime safety, fishing efficiency, and communication using AI-powered insights and real-time monitoring.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/santhosh18-M/OceanAI.git
cd OceanAI
```

### Install Dependencies

```bash
npm install
```

### Create Environment File

Create a `.env` file in the project root:

```env
VITE_AIS_API_KEY=YOUR_AIS_API_KEY
VITE_OPENWEATHER_API_KEY=YOUR_OPENWEATHER_API_KEY
```

### Run Application

```bash
npm run dev
```

Application will start at:

```text
http://localhost:5173
```

## 📊 System Workflow

1. Collect vessel data using AIS services.
2. Monitor maritime border proximity.
3. Fetch weather and marine conditions.
4. Analyze fishing opportunities.
5. Provide recommendations and alerts.
6. Notify users and family members.
7. Support emergency response through SOS system.
